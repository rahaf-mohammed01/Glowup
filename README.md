# 🛍️ GlowUp — Full-Stack E-Commerce Platform

> A full-stack fashion e-commerce web application featuring product discovery, customer accounts, shopping and wishlist functionality, checkout, order management, and administrative features.

## ✨ Overview

**GlowUp** is a full-stack e-commerce platform developed using **PHP, JavaScript, HTML, and CSS**.

The project was designed to simulate a real online shopping experience while exploring both **front-end development** and **server-side application logic**.

Users can browse fashion products, view product information, manage their shopping bag and wishlist, access their account, and proceed through the checkout process.
